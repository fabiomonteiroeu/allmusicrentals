## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Strapi → Next (fetchStrapi) | Resposta de terceiro entra no sistema e é validada por Zod |
| filtro de rota → query do Strapi | Valores de eixo viram fragmentos de chave de query |
| Strapi webhook → `/api/revalidate` | Requisição externa dispara purga de cache |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-14 | Tampering | `getProdutos`, filtro `subcategorias` | mitigate | Os slugs só chegam aqui depois de passar pela allowlist de `parseFiltrosDaUrl` (plano 06-02); o valor entra como VALOR de parâmetro, nunca como nome de chave — o índice `i`/`j` é gerado pelo código |
| T-06-15 | Tampering | `fetchStrapi` para `subcategorias`/`comparativo-led` | mitigate | Toda resposta passa por `subcategoriaColecao`/`comparativoLedUnico` antes de virar objeto de domínio — resposta malformada falha na borda, não na UI |
| T-06-16 | Spoofing | `POST /api/revalidate` | mitigate | Guarda de `x-revalidate-secret` já existente e inalterada; as entradas novas em `MODELO_TAG` só ampliam o mapa, não afrouxam a autenticação |
