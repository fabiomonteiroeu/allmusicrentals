Criar `cms/src/seed/upload-assets.ts` exportando
`garantirArquivoEnviado(strapi, nomeArquivo: string, alternativeText: string): Promise<number | null>`:

1. Procurar um arquivo já existente na biblioteca de mídia por nome, com
   `strapi.db.query('plugin::upload.file').findOne({ where: { name: nomeArquivo } })`. Se existir,
   devolver o `id` dele e NÃO enviar de novo — é a guarda de idempotência.
2. Resolver o caminho absoluto do asset a partir da raiz da aplicação Strapi:
   `path.resolve(strapi.dirs.app.root, 'seed-assets', nomeArquivo)`, com fallback para
   `path.resolve(process.cwd(), 'seed-assets', nomeArquivo)`. Se o arquivo não existir no
   filesystem, logar `strapi.log.warn` com o caminho tentado e devolver `null` — o seed continua
   sem hero em vez de derrubar o boot.
3. Ler `fs.statSync` para obter `size`, derivar `mimetype` da extensão (`.jpg`/`.jpeg` →
   `image/jpeg`, `.png` → `image/png`) e chamar
   `strapi.plugin('upload').service('upload').upload({ data: { fileInfo: { name: nomeArquivo,
   alternativeText } }, files: { filepath, originalFilename: nomeArquivo, mimetype, size } })`.
4. Devolver o `id` do primeiro item do array retornado. Envolver tudo em `try/catch` que loga com
   `strapi.log.error` e devolve `null`.

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-18 | Tampering | `seedConteudoCategorias` / `seedFaqDasCategorias` | mitigate | Toda escrita é condicional: só grava quando o campo está vazio ou o registro não existe. Edição feita pelo editor no admin nunca é sobrescrita por um redeploy |
