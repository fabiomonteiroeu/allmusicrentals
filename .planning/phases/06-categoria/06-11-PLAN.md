## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → `cms.allmusicbr.com` | Endpoints públicos novos passam a ser legíveis por qualquer um |
| internet → `/api/revalidate` | Webhook externo dispara purga de cache |
| operador → painel EasyPanel | Deploy manual com acesso a variáveis de ambiente |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-37 | Elevation of Privilege | permissões dos content-types novos em produção | mitigate | A verificação do passo 3 confere 200 em `find` e a ausência de qualquer rota de escrita pública; a correção de um 403 é feita em `PUBLIC_READ` no código, nunca no admin — o bootstrap continua sendo a única fonte de verdade |
| T-06-38 | Information Disclosure | `/api/comparativo-led/:id` exposto | mitigate | O single type não recebe `findOne` em `PUBLIC_READ` (exceção replicada de `settings-globais` no plano 06-01), e `draftAndPublish: false` elimina versão rascunho |
| T-06-39 | Spoofing | webhook de revalidação | mitigate | A guarda `x-revalidate-secret` já existente é reconfirmada no passo 4; nenhuma entrada nova em `MODELO_TAG` afrouxa a autenticação |
| T-06-40 | Tampering | redeploy sobrescrevendo conteúdo do editor | mitigate | Todas as funções de seed do plano 06-06 são condicionais (só gravam campo vazio ou registro inexistente); o passo 2 confere isso observando contagem zero nos logs de um segundo boot |
| T-06-41 | Denial of Service | boot do `cms` falhando em produção por seed | mitigate | Cada função de seed tem `try/catch` próprio com `strapi.log.error`; uma falha de conteúdo não impede o Strapi de subir |
| T-06-SC | Tampering | npm/pip/cargo installs | mitigate | Nenhuma dependência nova nesta fase — nada a auditar |
</threat_model>
