<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet/rede local → admin do Strapi (`0.0.0.0:1337`) | O container publica o admin em todas as interfaces da máquina |
| Cliente anônimo → API REST do Strapi | O role público define o que qualquer um lê sem token |
| Strapi (container) → Next (`host.docker.internal:3000`) | Chamada de webhook cruzando a fronteira do container |
| Máquina local → GitHub (`git push`) | Credencial de escrita no repositório remoto |
