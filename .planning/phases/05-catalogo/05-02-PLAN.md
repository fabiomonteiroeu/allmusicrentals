Construir a camada de lógica pura do catálogo antes de qualquer pixel: os schemas Zod da taxonomia
nova, a extensão de `getProdutos` para os 5 grupos de filtro com **AND entre grupos e OR dentro do

eventos.

Este plano vem primeiro de propósito (ordenação interface-first): 05-04 a 05-07 consomem estes
contratos, e recebê-los prontos evita que cada executor de UI vá caçar assinaturas pelo código.

**D-02** (o filtro "Categoria" opera sobre slugs das 5 categorias reais, nunca sobre subcategorias),
**D-05** (a união de eventos é o único formato aceito por `emitirEvento`), **D-09** (AND/OR).

Strapi, com o estado vindo da URL — a sintaxe já foi executada de verdade contra o Strapi
(`05-RESEARCH.md` §1) e a alternativa (baixar o catálogo e filtrar no cliente) não escala além de
algumas dezenas de produtos.

(entrada do usuário → query ao CMS) num único módulo auditável.
Output: `src/lib/catalogo/filtros.ts` novo; `schemas.ts`, `adapters.ts` e `dataLayer.ts` estendidos
de forma aditiva; testes unitários para cada um.
