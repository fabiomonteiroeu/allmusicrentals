## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → `searchParams` de `/[locale]/catalogo` | `?q=` e os parâmetros de filtro são integralmente controlados pelo visitante |
| `page.tsx` (servidor) → Strapi | A consulta ao CMS é montada a partir do que veio da URL |
| `error.tsx` → tela | Superfície onde detalhe de falha interna poderia vazar para o visitante |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
