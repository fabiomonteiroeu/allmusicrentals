**D5 — Os três grids por JS do catálogo viram `auto-fit` / coluna fixa.**
No layout, `heroCols`, `layoutCols` e `gridProdutos` são calculados em JavaScript a partir de
`this.state.vw`. Substituições, que são o alvo concreto a implementar em 05-04/05-05/05-07:
`heroCols` → `repeat(auto-fit, minmax(280px, 1fr))`; `layoutCols` → `272px minmax(0, 1fr)` fixo, com
o aside colapsando pelo drawer; `gridProdutos` → `repeat(auto-fit, minmax(280px, 1fr))`. Motivo:
idêntico ao já aceito em D1 e D3 — leitura de `window.innerWidth` causa mismatch de hidratação,
flash e CLS. Custo aceito: ±1 coluna em larguras intermediárias, o mesmo custo já aceito em D3.

**D6 — "Mais solicitados" passa a ordenar por um campo real, `contagemSolicitacoes`.**
No layout, a quinta opção do `<select>` de ordenação é `Mais solicitados`, e o modelo do Strapi não
tem campo correspondente. A opção **não é removida** (CATA-03 exige as 5 opções) e **não** vira
apelido de `destaque`. A divergência é a criação do atributo `contagemSolicitacoes`
(`integer`, `default: 0`, não localizado) em
`cms/src/api/product/content-types/product/schema.json`, com ordenação
`sort[0]=contagemSolicitacoes:desc` e `sort[1]=nome:asc` como desempate determinístico. Registrar
que o contador começa em 0 para todos os produtos e que **a Fase 9 é quem passa a incrementá-lo** no
Route Handler de envio da solicitação — enquanto isso, a ordenação é honesta (campo real, valor
real) e determinística pelo desempate por nome. Nenhum dado fictício é semeado.

**D7 — A visibilidade do botão `FILTROS` e o colapso do aside usam a media query única de 1080px.**
No layout, o botão só aparece quando `this.state.mobile` é verdadeiro (JS de viewport). A
implementação usa `media.mobile` / `media.desktop` de `src/lib/theme/media.ts`
(`theme.breakpoint.header`, 1080px), que é a única media query aprovada do projeto por D1 —
nenhum breakpoint novo é criado, respeitando D-07. Consequência registrada: o aside de 272px fica
visível a partir de 1080px e, abaixo disso, o mesmo painel é servido dentro do drawer. Resolve a
Q1 do UI-SPEC pela saída (a).
